# 🔍 AI Code Reviewer

A web app that reviews your code using AI and gives instant feedback.

## Tech Stack
- Frontend: React.js
- Backend: Python Flask
- AI: Google Gemini API

## Features
- Paste any code and get instant AI review
- Detects bugs and improvements
- Supports JavaScript, Python, React, HTML

## How to Run

### Backend
cd backend
pip install flask flask-cors google-genai python-dotenv
python app.py

### Frontend
cd frontend
npm install
npm start
